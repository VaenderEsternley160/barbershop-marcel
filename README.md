# BARBERSHOP MARCEL

## 1. Nama Usaha dan Pengantar

**Barbershop Marcel** merupakan usaha jasa pangkas rambut khusus pria yang menawarkan layanan potong rambut dengan gaya modern, rapi, dan sesuai keinginan pelanggan. Barbershop Marcel hadir untuk memberikan pengalaman potong rambut yang nyaman dengan pelayanan profesional, tempat yang bersih, serta harga yang terjangkau. Kami menyediakan berbagai pilihan gaya rambut, mulai dari gaya klasik hingga modern agar pelanggan dapat tampil lebih percaya diri.

## 2. Lembar Konsep Usaha

### A. Jenis Usaha
Barbershop Marcel merupakan usaha di bidang jasa, khususnya layanan pangkas rambut pria.

### B. Ciri Khas Usaha
- Menyediakan berbagai model potongan rambut modern dan klasik.
- Pelayanan ramah dan profesional.
- Tempat nyaman, bersih, dan modern.
- Harga layanan terjangkau.
- Pelanggan dapat memilih model rambut sesuai keinginan.

### C. Lokasi dan Tahun Berdiri
- Lokasi: Jl. Sungai Raya Dalam GG Mitra Indah Utama 7 No G3F
- Tahun berdiri: 1893.

### D. Pendiri
Barbershop Marcel didirikan oleh Marcel sebagai pemilik sekaligus pengelola usaha.

### E. Target Pelanggan
- Remaja laki-laki.
- Mahasiswa.
- Pekerja dan karyawan.
- Pria dewasa.
- Wanita dewasa

### F. Tiga Warna Utama

1. **Hitam (#111111)**
   Memberikan kesan elegan, maskulin, modern, dan profesional.

2. **Emas (#D4AF37)**
   Memberikan kesan mewah, eksklusif, dan berkualitas.

3. **Putih (#FFFFFF)**
   Memberikan kesan bersih, sederhana, dan mudah dibaca.

## 4. Cara Menjalankan Website

1. Pastikan komputer sudah memiliki browser seperti Google Chrome.
2. Buka folder project Barbershop Marcel.
3. Buka folder tersebut menggunakan Visual Studio Code.
4. Pastikan semua file HTML, CSS, tersedia.
5. Klik kanan pada file `index.html`.
6. Pilih **Open with Live Server**.
7. Website Barbershop Marcel akan terbuka di browser.

## 7. Catatan Proses Pengerjaan

### Kendala 1: Kesulitan Mengatur Tampilan Website
Kelompok mengalami kesulitan dalam mengatur tata letak website agar terlihat rapi dan menarik.

**Cara Mengatasi:**
Kami mencoba mengatur kembali CSS seperti ukuran tulisan, warna, jarak, dan posisi elemen website.

### Kendala 2: Kesulitan Membuat Website Responsif
Tampilan website terkadang kurang sesuai ketika dibuka melalui perangkat berbeda.

**Cara Mengatasi:**
Kami menggunakan CSS Responsive dan Media Query agar website dapat menyesuaikan ukuran layar komputer maupun smartphone.

### Kendala 3: Kesulitan Menghubungkan File
Beberapa bagian website tidak tampil karena kesalahan penulisan nama file atau lokasi folder.

**Cara Mengatasi:**
Kami memeriksa kembali struktur folder, nama file, serta alamat pemanggilan CSS dan JavaScript.
